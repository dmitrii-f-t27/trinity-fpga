## 3 доказанных шаблона (переиспользуемы)

### 1. decimal table+multiply (decimal32/64/128)
- `value = (-1)^s * C * 10^(E-bias)`, RNE to FP32.
- **Table Mf[de]** для de ∈ [non-trivial range]: de≥0 → 10^de (exact); de<0 → round(10^de × 2^G) (G=210 guard bits, error < 2^-157 < 0.5 ulp → bit-exact).
- mant_full = C × Mf (single multiply, NO divide). e2 = msb(mant_full) (de≥0) or msb-G (de<0).
- Extract 24-bit FP32 mantissa + guard/round/sticky → RNE round.
- Generator: `/tmp/gen_dec{64,32,128}_core.py` (Python, вычисляет Mf table + emits .v).
- Widths: decimal64=288, decimal32=240, decimal128=336. ALL ROUTED on openXC7 with heap+sa.

### 2. FP-add→FP32 (double_double, quad_double)
- value = exact sum of N FP64 limbs → round RNE to FP32.
- Align each mant53 >> (emax-eu) → signed accumulate → normalize (find MSB) → round 24-bit.
- Generator: hand-written .v (double_double at `/tmp/double_double_decode.v`, quad_double at `/tmp/quad_double_decode.v`).
- Golden: Fraction-based (exact dyadic, no double-round).

### 3. BRAM-LUT (takum16)
- 65536-entry BRAM (256KB fits XC7A200T BRAM), precomputed offline via mpmath.
- `$readmemh` loads .mem file. Trivial routing (no logic datapath).
- LUT generator: `/tmp/gen_takum16_lut.py` (replicates t27 witness decode law verbatim).

## takum32: PREP READY (core = next agent's first task)

### Что готово:
- ✅ Golden: `conformance/takum32_decode_conformance_ax7203.py` (committed `150a77e65`, mpmath oracle, N=32, validated: 0→0, +1→3f800000, -1→bf800000, NaR→7fc00000).
- ✅ 2^frac BRAM table: `/tmp/takum32_2frac.mem` (65536 × 48-bit, generated, verified: i=0→1.0, i=32768→√2).
- ✅ Approach verified: value = sign × exp(ell/2) = sign × 2^L where L = ell × log2(e)/2.
  - Range reduce: k = floor(L) → FP32 exp. frac = L - k → 2^frac via BRAM table + linear Taylor.
  - Precision: LOG2E_HALF needs ≥48-bit fixed-point. Linear correction (1 + f_lo×ln2) error ~2^-34 → enough for 24-bit FP32.
  - Datapath ~85-bit (smaller than decimal's 288-bit → routes easily).

### Что нужно сделать:
1. Compute constants: `C_Q48 = int(log2(e)/2 * 2**48)`, `LN2_Q48 = int(ln2 * 2**48)`. Use `mpmath.e` (NOT `mpf(2).exp(1)` — that was the bug). File-based Python (not -c, permission denied).
2. Write `takum32_decode.v`:
   - Extract ell_scaled_27 = (1-2S)(c×2^27 + M<<r_eff) from 32-bit code (same bit layout as takum16, N=32).
   - L_Q75 = ell_scaled_27 × C_Q48 (86-bit signed multiply).
   - k = L_Q75 >>> 75 (signed ASR). frac = L_Q75[74:0].
   - f_hi = frac[74:59] (16-bit). f_lo = frac[58:0].
   - table_val = BRAM[f_hi] (48-bit, $readmemh from takum32_2frac.mem).
   - x_Q48 = (f_lo × LN2_Q48) >>> 27 (correction).
   - mantissa = table_val + (table_val × x_Q48 >> 48).
   - Normalize + round to FP32.
3. Sim vs golden (iverilog TB). Expected 2-3 iterations.
4. Copy table to repo + wrapper (clone binary32's 32-bit frame) + workflow (clone decimal64's heap+sa).
5. Synth + flash + Tier-E → decode 42, Tier-E 72.

### Константы (compute via mpmath):
```python
from mpmath import mp, log, mpf, e
mp.prec = 200
LOG2E_HALF = log(e, 2) / 2  # = 1/(2*ln2) ≈ 0.72135
LN2 = log(2)
C_Q48 = int(LOG2E_HALF * (1 << 48))
LN2_Q48 = int(LN2 * (1 << 48))
```

## Ключевые уроки (для следующего агента)

1. **openXC7 routing**: large datapath (288-336-bit) ROUTES with `--placer heap` + ≥8 seeds (sa-only fails). ALWAYS try heap before concluding unroutable.
2. **-nodsp flag**: ALL GF MUL + decimal workflows MUST use `synth_xilinx -nodsp` (DSP48E1 inference = routing failure).
3. **Workflow seed search**: `for placer in heap sa; do for s in $(seq 1 8); do nextpnr ... --seed $s --placer $placer ...; done; done`.
4. **Sim-first**: iverilog TB vs Python golden (Fraction/Decimal/mpmath oracle) → iterate to bit-exact → THEN synth + flash.
5. **SHA injection**: always via `shasum` + sed placeholder, never hand-transcribe.
6. **No .sh files**: PreToolUse hook blocks .sh. Add tooling as `tri` subcommands or Python scripts.
7. **sudo -n openocd**: NOPASSWD may not survive reboot → re-verify `sudo -n true` at session start. Re-enable via `echo "$USER ALL=(ALL) NOPASSWD: /opt/homebrew/bin/openocd" | sudo tee /etc/sudoers.d/openocd`.
8. **Tooling bugs**: `gh --jq -r 'expr'` → gh treats -r as jq expression (empty output; use plain `--jq`). `gh api -f body=@file` stores literal path (use `--body-file`).
9. **Monitor for CI**: arm `Monitor` (persistent, 60s poll) for synth runs → flash immediately on completion.
