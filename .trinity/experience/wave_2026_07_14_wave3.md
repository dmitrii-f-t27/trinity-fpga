### Root cause: TIMING CLOSURE FAILURE

The GF64 adder core passes ALL iverilog tests (6/6 sequential, 1544/1544 Python bit-model) but fails on silicon regardless of TX pattern or synthesis flags. The failures are consistent with **setup timing violations**:

- 43-bit barrel shifter (`ma_ext >> ediff`)
- 24-bit exponent comparison
- 44-bit add/subtract for mantissa

GF32 (23-bit barrel shifter) meets timing → 11392/11392 bit-exact.
GF64 (43-bit barrel shifter) fails timing → ~50-70% pass rate.

**Fix: pipeline the adder** (add register stage in barrel shifter path).
